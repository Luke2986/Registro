## Solo per Claude Code

- Lancia sempre dalla radice del repository, così vengono caricate le istruzioni giuste.
- `/memory` mostra quali file di istruzioni sono attivi in questa sessione.
- Se correggo la stessa cosa due volte, scrivila in `AGENTS.md` come regola, togliendo quella che eventualmente contraddice. Non aggiungere regole dopo una singola sessione andata male: solo quando rappresentano una costante del progetto.
- Le preferenze personali che non riguardano il progetto stanno in `~/.claude/CLAUDE.md`, non qui.
